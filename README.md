# ziweiqi


一、工具描述<br>
一款根据目标单位名称和备案域名ip进行资产信息收集工具，资产准确率99.9%

二、适用场景<br>
护网比赛前期资产信息收集
单个/批量目标单位或备案域名资产的资产信息收集

三、运行环境<br>
如果运行环境有困难可以考虑使用 Windows Server 2022 Datacenter + python 3.9.11
